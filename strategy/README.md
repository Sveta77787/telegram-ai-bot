## Коротко

Проблема: охваты есть, продаж нет — между «посмотрел» и «заплатил» нет ни одного шага.

Решение: лестница из маленьких «да» — бесплатный тест в Telegram-боте → продукт за 390 ₽,
решающий одну острую боль → бесплатный разбор → личное ведение.

Первый продукт к запуску: **«Поясница. 14 дней по 10 минут»** — самая массовая боль
аудитории, минимальный риск, очевидный результат за две недели.

Данные о здоровье не собираются вообще: вместо анкеты — стоп-лист с одной кнопкой,
тест считается на устройстве человека, в базе лежат теги интереса, а не симптомы.

Красная линия: тренер не лечит. Все продукты — общеукрепляющие программы для людей
без острых состояний, с обязательным экраном безопасности и возвратом денег тем,
кому программа не подходит по здоровью.
