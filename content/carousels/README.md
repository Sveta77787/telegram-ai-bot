# Карусели

Здесь лежат тексты каруселей — по одному файлу на карусель.

## Как складывать новую карусель

Скажите Клоду в любом чате:

> Сохрани эту карусель в репозиторий `sveta77787/telegram-ai-bot`,
> в папку `content/carousels/`, по шаблону `_TEMPLATE.md`.

Или скопируйте текст сюда вручную.

## Правила именования файлов

```
YYYY-MM-DD-короткое-название.md
```

Например: `2026-08-19-5-oshibok-v-storis.md`

- дата — когда карусель написана;
- название — латиницей, строчными, слова через дефис;
- расширение всегда `.md`.

## Формат файла

Каждый файл начинается с блока метаданных (front-matter) между `---`,
дальше идут слайды. Полный образец — в [`_TEMPLATE.md`](_TEMPLATE.md).

Обязательные поля метаданных:

| Поле       | Что писать                                        |
|------------|---------------------------------------------------|
| `title`    | Название карусели человеческим языком             |
| `topic`    | Тема / рубрика                                    |
| `date`     | Дата в формате `YYYY-MM-DD`                       |
| `platform` | instagram / telegram / linkedin / …               |
| `slides`   | Сколько слайдов                                   |
| `status`   | `draft` — черновик, `ready` — готово, `published` — опубликовано |

Слайды — заголовки уровня `##`, по одному на слайд, строго по порядку.
Текст подписи к посту — в конце, в разделе `## Подпись к посту`.

## Список всех каруселей

Реестр лежит в [`INDEX.md`](INDEX.md). Он собирается автоматически:

```bash
python3 content/carousels/build_index.py
```

Скрипт читает метаданные всех `.md` в папке и переписывает `INDEX.md`.
Запускайте после того, как добавили новый файл.
