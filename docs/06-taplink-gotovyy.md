# Готовый таплинк: текст всех блоков по порядку

Копируй блоки сверху вниз прямо в Taplink. В квадратных скобках — подставить своё.
Как технически собрать (регистрация, страницы, ссылки) — в strategy/06-taplink.md
и strategy/11 (раздел 3). Здесь — только готовый текст.

Правило: на таплинке **нет форм** (ни имени, ни телефона). Все действия — кнопкой
в Telegram. Цену продуктов показываем, но кнопка ведёт в Telegram, оплата там.

---

## БЛОК 1. Шапка

**Фото:** тренер в полный рост или по пояс, светлое помещение, спокойная поза,
взгляд в камеру. НЕ в зале с железом за спиной.

**Имя:**
```
[Имя Фамилия]
```

**Строка позиционирования:**
```
Возвращаю к движению после 30. Дома, без зала, без фанатизма.
```

**Строка-дисклеймер (мелким):**
```
Не врач. Не лечу. Помогаю двигаться тем, кто давно не двигался.
```

---

## БЛОК 2. Главная кнопка (одна, крупная)

```
🎁 Бесплатный тест: где у вас слабое звено
7 минут, нужен только стул и стена
```
**Ведёт:** на страницу теста (когда будет готова) или пока — в Telegram-канал.

---

## БЛОК 3. Короткий текст «кому это»

```
Если к вечеру спина как деревянная, утром надо расхаживаться,
а идти в зал страшно и непонятно — вам сюда.
Здесь нет марафонов, срывов и «потерпи ещё подход».
Есть короткие понятные шаги по 10 минут в день.
```

## БЛОК 4. Продукты (карточки-кнопки)

### Карточка 1 — готова к продаже
```
💚 Поясница. 14 дней по 10 минут — 390 ₽
Чтобы к вечеру спина не была деревянной.
Дома, без инвентаря. Первым 30 покупателям — 190 ₽.
```
**Ведёт:** в Telegram-бота/канал: `t.me/[бот_или_ник]?start=back`

### Карточка 2 — скоро (можно показать как «готовится»)
```
🧣 Шея и холка. 21 день — 390 ₽
Чтобы шея не каменела, а плечи развернулись. Скоро.
```

### Карточка 3 — скоро
```
🦵 Колени. 4 недели — 390 ₽
Чтобы спускаться по лестнице без «ой». Скоро.
```

## БЛОК 5. Личная работа с тренером (его главная услуга)

```
🎯 Личное ведение с тренером

Программа собирается под вас: ваш возраст, ваш режим, ваши ограничения,
ваш инвентарь (или его отсутствие). Не универсальный комплекс, а то,
что подходит именно вам.

Что входит:
• персональная программа под ваши цели и ограничения
• разбор техники по вашим видео — чтобы вы делали правильно
• связь со мной в течение недели, отвечаю на вопросы
• корректировка программы раз в 2 недели по вашему прогрессу

Как это работает: сначала — бесплатный разбор 15 минут. Я смотрю, что у вас,
и говорю честно, чем могу помочь, а чем нет. Без давления и без «купите прямо сейчас».

Беру [N] человек в месяц.
```
**Кнопка:**
```
📞 Записаться на бесплатный разбор
```
**Ведёт:** в личку тренера `t.me/[ник]`

## БЛОК 6. Немного о тренере (доверие)

```
Меня зовут [Имя]. Я тренер. Сам пришёл к движению не от большого спорта,
а [1–2 честные фразы: например «после того, как в 30 с лишним не смог
подняться по лестнице без одышки»]. Знаю, каково начинать с нуля,
когда тело отвыкло. Поэтому не гоняю, а возвращаю к движению аккуратно.

Не врач. С острой болью и травмами — сначала к врачу, это честно и важно.
```

*(Заменить квадратные скобки на реальную короткую историю тренера — 2–3 фразы,
без пафоса. Это самый читаемый блок после кнопки.)*

---

## БЛОК 7. Отзывы

Пока отзывов нет — блока нет. Появятся после первых покупателей: скриншоты
переписки (с разрешения, имена замазать). Никаких «избавился от грыжи» —
только «стало легче вставать по утрам», «спина к вечеру не ноет».

## БЛОК 8. Подвал (мелким, но обязательно)

```
Публичная оферта · Политика конфиденциальности · Согласие на обработку данных
[Имя Фамилия], самозанятый(ая), ИНН [000000000000]
Материалы носят информационный характер, не являются медицинской услугой
и не заменяют консультацию врача.
```
**Ссылки** ведут на страницы с документами (Telegraph или страницы Taplink).
