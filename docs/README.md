# Готовые документы

Шаблоны для самостоятельного оформления. Подставьте свои данные вместо всего,
что в квадратных скобках.

| Файл | Куда |
|---|---|
| [01-oferta.md](01-oferta.md) | Отдельной страницей на таплинке. Ссылка обязана открываться **до** оплаты |
| [02-politika-konfidencialnosti.md](02-politika-konfidencialnosti.md) | Отдельной страницей на таплинке, ссылка на первом экране бота |
| [03-soglasie-pdn.md](03-soglasie-pdn.md) | Короткий текст — в бота, полный — страницей на таплинке |
| [04-korotkie-teksty.md](04-korotkie-teksty.md) | Шапка профиля, плашки в видео, экраны бота, ответы на комментарии |

Разбор рисков и порядок действий — в [strategy/09-yuridicheskaya-samozashchita.md](../strategy/09-yuridicheskaya-samozashchita.md).

**Это шаблоны по типовой практике, а не юридическая консультация.** Они закрывают
основную часть повседневных рисков. Когда пойдут стабильные деньги, отдайте пакет
юристу на разовую вычитку — это стоит недорого и делается за пару дней.

## Перед публикацией заменить

```
[Фамилия Имя Отчество]     — полностью, как в паспорте
[000000000000]             — ИНН
[@имя_бота]                — юзернейм бота
[@ник]                     — ваш личный ник в Telegram
[адрес]                    — электронная почта для обращений
[Город]                    — город
[ДД.ММ.ГГГГ]               — дата редакции
[ссылка]                   — адреса страниц на таплинке
[ЮKassa / Робокасса]       — выбранный платёжный сервис
[название хостинга]        — где физически стоит база бота
[390]                      — цена
```

Проверьте поиском, что квадратных скобок в опубликованных документах не осталось.
