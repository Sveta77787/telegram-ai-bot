## Суть в трёх абзацах

Проблема: охваты есть, продаж нет — между «посмотрел» и «заплатил» нет ни одного шага.

Решение: лестница из маленьких «да» — контент → Telegram-канал → продукт за 390 ₽,
решающий одну острую боль → бесплатный разбор → личное ведение.

Порядок работ: **сначала продать вручную тридцать раз** через закрытый Telegram-канал,
автоматику собирать только после того, как спрос подтвердился. Первый продукт —
«Поясница. 14 дней по 10 минут».

Красная линия: тренер не лечит. Все продукты — общеукрепляющие программы для людей
без острых состояний, с обязательным экраном безопасности и возвратом денег тем,
кому программа не подходит по здоровью. Данные о здоровье не собираются вообще.
